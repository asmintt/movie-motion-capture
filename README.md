# ムービー・モーションキャプチャ

先生と初心者（2人、またはどちらか1人）が映った練習動画から、骨格つき動画（MP4）と骨格データ（CSV）を作るWebアプリ。
iPhoneのSafariで開いて使う。動画はブラウザの中だけで処理され、外部には送られない。

公開アドレス：https://asmintt.github.io/movie-motion-capture/

## 使い方

1. 動画を選ぶ
2. 解析する対象（2人・先生のみ・初心者のみ）、範囲、速さ（1/4・1/2・等倍・2倍）、AIの精度を決める
3. 対象の人をタップで選ぶ（ずれた点はドラッグで直せる）
4. 解析する：骨格の検出と、動画・CSVの作成を1回で行う
5. 手元に残したいときだけ、動画（写真アプリ）とCSV（ファイルアプリ）を保存する
6. 「Claudeで分析」：骨格データをコピーし、分析用Artifactを開く（URLは `app.js` の `ANALYSIS_URL` に入れる）

2人が重なったコマは、CSVの `overlap` 列を1にする（取り違えや点のずれのおそれ）。何度も重なる動画は、1人ずつ解析し直す。

## しくみのメモ

- 速さのため、骨格AIを動かすのは毎秒10コマ（`ANALYZE_FPS`）。書き出す動画（毎秒30／15コマ）の間のコマは、前後の結果から補間する。CSVの行は、すべて実際に検出したコマ
- 動画は1コマずつシークせず、開始位置へ1回だけ移動してから再生し、流れてくるコマを受け取る（`requestVideoFrameCallback`）。検出するコマでは再生を止めて解析し、終わったら再生を続ける。この仕組みがない端末や、再生が止まったときは、これまでどおり1コマずつシークして読む
- 再生中のコマを受け取るため、解析中は解析用の動画を画面に小さく表示する（表示していないとコマが届かない端末がある）
- 画面全体だと遠い人や暗い服の人を見落とすため、人ごとに前のコマの位置の周りを縦長に切り出し、拡大して検出している
- 頭の点（顎先・頭頂部）：顔用AIは使わず、骨格AIの目と口から推定する（AIの点ではない）。比率は人ごとに、人を選んだときの位置（手で直した場合は直した後）から測る。目と口の自信が低いコマは灰色で表示する
- 頭頂部 → 顎先 → 両肩の真ん中 を線でつなぎ、頭と首の傾きが見えるようにしている
- 保存するファイル名は `元の名前_MediaPipePose.mp4` と `元の名前_MediaPipePose.csv`
- 動画の書き出しはWebCodecs（H.264）。iPhoneはiOS 16.4以降が必要
- 動作確認用に `?src=動画のURL` で動画を読み込める

## ローカルで動かす

```bash
cd ~/Desktop/movie-motion-capture && python3 -m http.server 8765
```

ブラウザで http://localhost:8765/ を開く。
